利用規約

この利用規約（以下「本規約」といいます。）は、Koki Egawa（以下「運営者」といいます。）が提供する古銭・記念コインの台帳アプリ「コイン台帳」（以下「本アプリ」といいます。）の利用条件を定めるものです。本アプリをご利用になる前に、本規約をお読みください。本アプリを利用された場合、本規約に同意したものとみなします。

第1条（本アプリの内容）

本アプリは、利用者が所持するコインを写真・銘柄・状態などとともに記録して管理し、同梱のカタログから銘柄の候補を探し、買取相場の目安を参考として確認するためのツールです。

第2条（候補・相場の目安についての注意）

1. 本アプリの「候補を探す」は、利用者が選んだ特徴（素材・額面・発行年・モチーフ）で同梱カタログを絞り込む補助機能です。写真から銘柄を自動で判定するものではなく、候補が正しい銘柄であることを保証しません。銘柄の確定は利用者ご自身で行ってください。

2. 本アプリが表示する相場は、運営者が調査して同梱した買取相場の「目安」です。実勢価格や査定結果ではなく、実際の買取・売却価格を保証するものではありません。データがない銘柄は「相場データ不足」と表示し、数値を表示しません。

3. 本アプリは、真贋の判定や専門家による鑑定に代わるものではありません。売買や買取の判断は、利用者の責任で、必要に応じて専門家や買取事業者にご相談のうえ行ってください。

4. 運営者は、本アプリの情報に基づく売買・買取・出品などによって生じた損害について、第11条の範囲で責任を負います。

第3条（無料プランと Premium）

1. 本アプリには、無料で利用できる機能と、有料プラン（以下「Premium」といいます。）で利用できる機能があります。

2. 無料プランでは、台帳の管理（登録・編集・削除・写真・統計・検索・並び替え）を無制限に、「候補を探す」を月5回まで、相場の目安は全体のレンジをご利用いただけます。

3. Premiumでは、「候補を探す」が無制限になり、相場の目安の詳細（状態別レンジ・推移メモ）をご利用いただけます。ただし、相場の詳細は、同梱データに根拠のある銘柄についてのみ表示されます。

4. 提供する機能や範囲は、将来変更される場合があります。

第4条（Premiumの料金・自動更新）

1. Premiumの料金プランは次のとおりです。週額プラン・買い切りプランはありません。

　・月額プラン（自動更新サブスクリプション）：月額680円

　・年額プラン（自動更新サブスクリプション）：年額5,800円

実際の請求金額・通貨・税の扱いは、購入時にApp Storeの購入画面に表示される内容に従います。

2. 料金は、購入の確認時（無料期間がある場合は、無料期間の終了時）に、利用者のApple IDアカウントへ請求されます。

3. 月額・年額プランは、現在の期間が終了する24時間以上前に自動更新をオフにしない限り、同じ期間・同じ料金で自動的に更新されます。

4. 更新時の料金は、現在の期間が終了する24時間以内にApple IDアカウントへ請求されます。

5. 価格は将来変更される場合があります。価格が変更される場合は、Appleの定める手続きに従ってお知らせします。

第5条（無料期間：1か月間無料）

1. 年額プランには、初めてご利用の方を対象に、1か月間の無料期間（無料のイントロダクトリーオファー）があります。月額プランには無料期間はありません。

2. 無料期間は、Apple IDごとに、同じサブスクリプショングループ（「プレミアム」）につき1回に限り利用できます。過去に同グループの無料期間または導入オファーを利用したことがある場合は、対象外となります。対象かどうかは、購入画面で表示される内容に従います。

3. 無料期間中に、終了の24時間以上前に解約した場合、料金は請求されません。

4. 無料期間を解約せずに終了した場合、終了時に年額プランの料金（5,800円）が請求され、以降は自動的に更新されます。

5. 無料期間の未使用分は、利用者がPremiumを購入した時点で失われる場合があります。

第6条（解約・プラン管理・購入の復元）

1. 解約およびプランの管理は、端末の「設定」アプリ > 利用者の名前 > 「サブスクリプション」から、いつでも行えます。

2. 本アプリをアンインストールしても、サブスクリプションは自動的には解約されません。解約する場合は、上記の手続きを行ってください。

3. 解約した場合でも、すでに支払い済みの期間が終了するまでは、Premiumの機能を利用できます。

4. 機種変更・再インストールの際は、本アプリの設定画面または購入画面にある「購入を復元」から、同じApple IDで購入したPremiumの状態を復元できます。
